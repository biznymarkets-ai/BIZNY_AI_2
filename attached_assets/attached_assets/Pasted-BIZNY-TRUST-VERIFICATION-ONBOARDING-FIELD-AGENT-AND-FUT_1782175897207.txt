FIELD AGENT WORKFLOW

A verification request should be created when a user needs proof.

Examples:

Verify business location
Verify milestone completion
Verify market day activity
Verify product availability
Verify delivery
Verify facility
Verify deal milestone

Workflow:

User requests verification.
System creates verification request.
Field Agent accepts or is assigned.
Field Agent visits, reviews, or confirms remotely where acceptable.
Field Agent uploads evidence.
Evidence may include photos, videos, notes, documents, location stamp, and timestamp.
Field Agent submits verification result.
System updates the related object status.

Verification evidence should be attached to the relevant object:

Profile
Business
Execution
Milestone
Marketplace listing
Deal
Market Day

PARTY AGREEMENT FLOW

A deal should not become active immediately.

Flow:

Deal draft created.
Parties review terms.
AI summarizes deal in plain language.
Parties edit terms if needed.
Witnesses are added if needed.
Field Agent verification is requested if physical asset, location, product, facility, delivery, or milestone is involved.
Each party clicks: I have reviewed and agree to these terms.
System records timestamp.
Deal becomes Active.

FUTURE ESCROW STRUCTURE

Do not build real escrow yet.

But design statuses and UI placeholders for future escrow.

Future escrow concept:

Funds are held by Bizny or a licensed escrow/payment partner.
Funds are released only after milestone completion and confirmation.
Buyer confirmation or Field Agent verification may be required.
Disputed milestones should pause release.

For now, show escrow as:

Coming Soon
Future Trust Feature
Not Active Yet

Do not process payments.
Do not create wallets.
Do not create withdrawable balances.
Do not create Bizny Coin yet.

DEAL DESK DISCLAIMER

Display this disclaimer in Deal Desk:

Bizny provides a coordination interface to help users structure, document, verify, and track deals. Bizny is not a bank, escrow provider, legal representative, guarantor, investment advisor, or law enforcement body.

Users are responsible for performing their own due diligence, verifying identities, reviewing documents, confirming business registration, inspecting locations, and seeking independent legal, financial, or professional advice before entering any agreement.

Bizny encourages milestone-based execution, field agent verification, witness confirmation, and careful review before proceeding with any deal.
